# IP Character Design

面向 AI Agent 的 IP 角色制作技能，覆盖角色定位、文化转译、形象设计、表情动作、应用延展与质量验收。

本项目将角色制作中的设计决策整理为可复用流程，帮助 Agent 建立角色身份基准，并在不同视角、表情和载体中检查一致性。适用于文旅 IP、品牌吉祥物、博物馆角色、活动形象和角色家族。

## 能做什么

| 任务 | 主要内容 |
|---|---|
| 从零策划 | 整理需求、定义受众与定位、比较设计方向 |
| 文化转译 | 区分来源事实与原创设定，将文化依据转为形态、结构或行为 |
| 角色定型 | 定义轮廓、比例、五官、标志特征、配色与性格 |
| 视觉制作 | 在运行环境支持时生成或编辑主形象、三视图、表情和动作 |
| 应用延展 | 制作头像、贴图、包装或周边方向，检查载体适配 |
| 一致性修订 | 对照角色基准定位漂移问题，修订并记录影响 |

本技能中的 IP 指角色型 IP，不用于网络地址配置、个人账号运营或知识产权法律咨询。

## 制作流程

```text
需求与定位
    ↓
设计依据与方向
    ↓
角色身份基准
    ↓
主形象制作
    ↓
表情、动作与应用延展
    ↓
验收、修订与交付
```

根据任务从相应阶段进入。已有角色做表情延展时，沿用现有身份基准；只要求定位方案时，交付文字方案即可。

## 使用条件

- 使用能够加载 `SKILL.md` 的 Agent 环境。下方安装和调用示例面向 Codex。
- 核心技能由 Markdown 指令和 YAML 元数据组成，使用这些指令不需要安装 Python 或 Node.js。可选文件检查脚本需要 Python 3.9 或更高版本，仅使用标准库。
- 实际出图需要运行环境提供图像生成或编辑工具。本技能不附带图像模型、API Key 或出图额度。
- 文化事实核查需要可用的检索工具或用户提供的可靠资料。
- 其他 Agent 的技能发现机制可能不同，请按其文档配置；本项目尚未完成跨平台验证。

## 安装到 Codex

### 通过 GitHub 链接安装（推荐）

将下面整段内容复制到 Codex 发送，由安装器下载并安装，无需手动解压和复制文件：

```text
请使用 $skill-installer 安装这个 GitHub 仓库中的技能：
https://github.com/Luskeysiegert-UX/ip-character-design
SKILL.md 位于仓库根目录，技能目录请命名为 ip-character-design。
请安装到当前 Codex 支持的个人技能目录，并检查安装后的文件是否完整。
```

此方式需要 Codex 能访问 GitHub 并写入个人技能目录；出现网络或目录授权请求时，按实际需要授权。私有仓库还需要对应账号的访问权限。链接用于指定安装来源，单击网页链接本身不会自动完成安装。

安装完成后，在下一条消息中使用 `$ip-character-design`；如果未被识别，重启 Codex 后再试。若当前环境没有 `$skill-installer`，使用下方手动安装方式。

### 手动安装（备用）

1. 在 GitHub 仓库页面选择 **Code → Download ZIP**，解压文件。
2. 找到包含 `SKILL.md`、`agents` 和 `references` 的目录，将该目录命名为 `ip-character-design`。
3. 将整个目录复制到个人技能目录 `~/.agents/skills/`。Windows 可在文件资源管理器地址栏输入 `%USERPROFILE%\.agents\skills`；目录不存在时手动创建。
4. 在 Codex 中调用技能。如果没有出现，重启 Codex 后再试。

安装后的结构应为：

```text
~/.agents/skills/ip-character-design/
├── README.md
├── SKILL.md
├── agents/
│   └── openai.yaml
├── scripts/
│   └── check_package.py
└── references/
    ├── workflow.md
    ├── character-system.md
    ├── quality.md
    └── project-record.md
```

确保 `SKILL.md` 直接位于 `ip-character-design` 内，避免多嵌套一层目录。

### 项目内安装

若希望随特定项目共享，将整个技能目录放到该项目的 `.agents/skills/ip-character-design/`。在该项目中使用 Codex 时可发现项目技能。

技能目录及发现方式参考 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 快速开始

在 Codex 输入 `$ip-character-design`，并说明具体任务。首次试用可先完成一个文字方案：

```text
请使用 $ip-character-design，为一个地方博物馆策划角色 IP。
受众是亲子家庭，主要用于馆内导览和社交媒体。
先完成定位和两个有实质差异的设计方向，本次不用生成图片。
文化事实请标明依据，缺少资料的部分列为待核查项。
```

### 制作主形象

```text
请使用 $ip-character-design，根据我提供的品牌资料制作一个吉祥物。
受众是 18–30 岁的年轻人，主要用于头像和活动物料。
先建立角色身份卡，再生成一张完整主形象并检查结果。
配色沿用附件中的品牌色，输出 PNG；如当前工具无法出图，请明确说明。
```

### 延展已有角色

附上现有角色图片，再输入：

```text
请使用 $ip-character-design，以附件角色为基准制作四个表情：
开心、疑惑、惊讶、鼓励。
保持头身比、五官结构、身体配色和标志特征不变。
先检查一个表情样例的一致性，再继续其他表情。
```

### 修订角色漂移

附上基准图与需要修订的图片，再输入：

```text
请使用 $ip-character-design，对照基准图修订这组三视图。
重点检查耳朵形状、尾巴连接位置和正侧背比例。
只修改不一致的部分，保留原有配色和表现方式，并记录修订结果。
```

```text

已有角色、品牌资料或文化依据：
必须保留的特征：
本次需要的产物与数量：
尺寸、格式或生产要求（如有）：
```

## 交付与质量检查

根据请求，交付可以包含需求简报、角色身份卡、图像资产、制作提示词、应用说明和验收记录。不会要求每次都生成全部产物。

检查重点包括需求契合、身份一致、形体结构、视觉层级和实际文件可用性。按照用途补充缩小、轮廓、单色或应用测试。

- 没有实际生成和查看图片时，视觉检查标为未验证。
- 角色三视图不自动等同于可开模的工程图纸。
- 周边效果图不替代打样；生产适配按实际验证状态说明。
- 角色一致性依赖参考资产、工具能力和修订过程，本技能不保证一次生成即达到要求。

## 更新后的文件检查

维护者可在仓库根目录执行：

```shell
python scripts/check_package.py
```

脚本不修改文件、不联网、不安装依赖。成功返回退出码 0，漏文件或引用损坏返回 1。该检查不解析 YAML、不检查远程链接，也不代替官方校验、图像验收或真实安装测试。
