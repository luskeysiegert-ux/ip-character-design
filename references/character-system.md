# 角色身份与延展规则

## 身份卡

以能指导下一次制作的精度填写，不用“保持一致”替代具体描述。

| 字段 | 记录内容 |
|---|---|
| 身份 | 名称、角色职责、受众、性格及典型行为 |
| 主轮廓 | 主要体块、重心、耳/角/尾等轮廓特征 |
| 比例 | 头身比、头与躯干宽度关系、四肢长度关系；优先相对值 |
| 五官 | 眼形与间距、鼻口位置、眉毛结构，使用头宽或头高为参照 |
| 标志特征 | 形状、数量、固定位置和朝向；“左/右”采用角色自身视角 |
| 配色 | 主色、辅助色、强调色及身体分区；精确色值属于规范，需检查实际图像偏差 |
| 表现 | 线条、二维/三维、材质、阴影与纹理规则 |
| 变化边界 | 哪些永远固定，哪些随情绪变化，哪些可随场合替换 |
| 基准 | 对应图片/文件、版本、用户确认或工作基准状态 |

例如：耳尖缺口固定在角色左耳；脸颊标记随面部透视移动，但数量和归属不变。不能为了正面可见而把背面的结构移到正面。

## 三视图

正面、明确朝向的侧面、背面采用同一比例与姿态逻辑，统一头顶、肩、腰、脚底高度。检查厚度、连接点、尾巴根部、服饰开合与背面结构是否相互解释。不把三幅不同姿势图当作三视图。

用于建模时优先平视、近正交、简洁光照。单张生成的多视图可能自相矛盾，必须逐视角检查。缺少尺寸、材料与结构细节的角色设定图仅为设计参考，不能宣称可直接开模。

## 表情与动作

表情通过眉眼、嘴型与身体姿态表达。保留脸部比例和标志特征；允许卡片注明的夸张，不以变脸增强情绪。表情是否有效由可观察差异判断，文字标签不能代替情绪表现。

动作体现角色行为和场景，例如招呼、引导、观察、搬运。检查受力、接触点、关节、遮挡及身体结构。按角色设定检查肢体数量，不强制卡通角色采用人类手指结构。

## 应用与角色家族

| 应用 | 需要检查 |
|---|---|
| 头像/小图标 | 实际目标尺寸下五官和标志是否可见；必要时建立有据可循的简化版 |
| 表情贴图 | 情绪辨识、轮廓边缘、透明背景是否真实存在；文字保持可读 |
| 印刷/包装 | 实际尺寸、留白、印刷方给出的出血和色彩要求；不捏造通用参数 |
| 玩偶/立体 | 悬空件、薄弱连接、重心、材质与拆件方向；明确待打样项 |
| 动画 | 转面关系、关节活动、遮挡、可动件；展示图不等于绑定模型 |
| 角色家族 | 共用形体与表现规则；成员以轮廓、比例、行为区分，不只换色 |

延展发现结构不成立时，先判断是否可在既定身份内修复。若必须改变核心特征，明确变更影响并按用户要求决定，更新所有关联资产的版本状态。
